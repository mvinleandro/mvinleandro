### 📖 About Me
I specialize in writing optimized native code and deploying machine learning models directly onto resource-constrained microcontrollers (ESP32, STM32, Arduino) and edge devices (Raspberry Pi). My engineering foundation comes from competitive robotics, where a millisecond delay or a memory leak in the physical world means failure. I bring that same strict hardware-first mindset to IoT products, focusing on native C/C++ architecture, RTOS, and TinyML.

When I am not writing bare-metal firmware, I am building cross-platform mobile dashboards (Flutter) to monitor and control headless hardware over BLE/Wi-Fi. Recently, I built a custom C++ micromouse simulator from scratch, featuring an ASCII terminal visualizer for pathfinding logic.

Need custom ML models deployed to hardware or an IoT dashboard built? **[Let's work together on Fiverr!](https://www.fiverr.com/mvinleandro)**

🌍 **Fun Fact:** I'm a polyglot! I speak **Portuguese** (Native), **English** (Bilingual), **Spanish** (Professional), **French** (Professional), and even some **Latin**.
